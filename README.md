# C# Classes and Objects – Basic Programs

This repository contains **simple C# console programs** that demonstrate the use of **classes and objects** with basic calculations.  
These programs are designed for **beginners** and are suitable for **university assignments and lab work**.

## 📌 Programs Included

### 1️⃣ Addition & Subtraction Calculator
This program takes two numbers from the user and performs:
- Addition
- Subtraction

It demonstrates:
- Class creation
- Object usage
- Input from user
- Simple arithmetic operations

📄 **File:** (https://github.com/duaafatima328-blip/duaa_fatima/blob/main/example1.cs)

---

### 2️⃣ Area Calculator
This program calculates the **area of a rectangle** using length and width entered by the user.

It demonstrates:
- Class with data members
- Method to calculate area
- Object calling class methods

📄 **File:** (https://github.com/duaafatima328-blip/duaa_fatima/blob/main/example3.cs)

---

### 3️⃣ Total Marks and Average Calculator
This program takes marks of five subjects and calculates:
- Total marks
- Average marks

It demonstrates:
- Multiple variables in a class
- Simple calculations
- Output formatting

📄 **File:** (https://github.com/duaafatima328-blip/duaa_fatima/blob/main/Program.cs)

## ▶ How to Run the Programs
1. Open **Visual Studio**
2. Create a **Console App (.NET Framework)**
3. Copy any `.cs` file code into the project by opening this through the given link and downloading from there.
4. Run using **Ctrl + F5** or simple click start button on screen.
